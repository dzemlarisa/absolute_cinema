# О проекте

Absolute Cinema — это веб-приложение для онлайн-бронирования и покупки билетов в кинотеатры. Система разработана для автоматизации работы справочной службы кинотеатров и предоставления удобного сервиса для посетителей.

# Основные возможности

Для пользователей:

- Просмотр актуального списка фильмов с фильтрацией по жанрам

- Просмотр кинотеатров и информации о залах

- Покупка билетов на выбранный сеанс

- Регистрация и авторизация в системе

Для администраторов:

- Управление фильмами (создание, редактирование, удаление)

- Управление кинотеатрами и залами

- Управление сеансами
